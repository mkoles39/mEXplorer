# mEXplorer — Güvenlik Politikası

## Güvenlik Açığı Bildirme

Bir güvenlik açığı bulduysanız, lütfen doğrudan proje sahibiyle iletişime geçin:

- GitHub Issues üzerinden "Security" etiketi ile bir issue açın, veya
- [mkoles39/mEXplorer](https://github.com/mkoles39/mEXplorer) deposunun security advisory bölümünü kullanın

Güvenlik açıkları **herkese açık bir issue olarak açıklanmamalıdır**. İlk olarak özel olarak bildirin ve düzeltme yayınlanana kadar bekleyin.
