# mEXplorer — Katkıda Bulunma Rehberi

Teşekkür ederiz! mEXplorer'ı daha iyi hale getirmek için katkıda bulunmayı düşünüyorsunuz.

## Nasıl Katkıda Bulunabilirim?

1. **Fork yapın** — Bu depoyu kendi hesabınıza fork'layın
2. **Yeni branch oluşturun** — `git checkout -b feature/ozellik-adiniz`
3. **Değişiklikleri yapın** — Kod, çeviri veya dokümantasyon iyileştirmeleri
4. **Test edin** — Uygulamayı çalıştırarak değişikliklerinizi doğrulayın
5. **Pull Request gönderin** — Değişikliklerinizi ana depoya önerin

## Kod Stil Kuralları

- JavaScript dosyaları: **UTF-8**, **CRLF** satır sonu
- Hex sabitler: Mutlaka `0x` öneki ile yazılın (`Ox` yanlıştır)
- Türkçe çeviriler: `lang/tr.xml` dosyasında, doğru yazım ve dil kuralları
- XML dosyaları: UTF-8 encoding, doğru escaping
